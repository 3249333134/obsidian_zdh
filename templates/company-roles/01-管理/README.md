# 管理知识库

## 分类
- 目标与经营指标
- 经营决策与取舍
- 公司制度与职责
- 战略与规划
- 会议与协同
- 风险与应急
- 人才与授权方法
- 经营复盘

## 整理规则
围绕目标、依据、取舍、责任和结果整理。区分讨论、建议、已批准决策及已失效制度；记录批准人、适用范围和生效条件。指标必须注明期间、口径、来源，目标不能写成实绩。会议保留结论、分歧、行动和未决问题，不保存逐字流水账。薪酬、个人人事评价等敏感资料单独核对授权。AI不能代替审批或扩大空间权限，缺失责任人、金额和日期保持待确认。

## 常用问题
- 已发布的经营决策有哪些共同依据和主要取舍？
- 哪些制度说明了适用范围、负责人和例外处理？
- 现有复盘中反复出现哪些风险，已有应对方法是什么？
- 哪些经营指标存在口径差异，能否按来源对照？
- 跨部门协作有哪些已验证的做法？
- 哪些结论仍有待验证的前提？请列出引用。

## 可手动创建的个人计划
- 核对本周目标与指标口径
- 跟进待决事项与责任确认
- 检查经营风险及应对进展
- 完成经营周复盘并整理可复用决策
