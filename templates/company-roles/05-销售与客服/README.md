# 销售／客服知识库

## 分类
- 客户画像与需求
- 商机与跟进
- 产品方案与演示
- 报价与商务规则
- 客户FAQ
- 工单与客诉处理
- 客户成功与续费
- 失单与服务复盘

## 整理规则
围绕客户场景、真实需求、产品匹配、处理过程和结果整理；客户原话、销售判断、已批准承诺和实际交付分开。记录适用版本和问题复现条件，FAQ需有核实依据与升级路径。报价、折扣、交付时间和赔付仅引用已批准规则，不把建议当承诺。客户姓名、联系方式、合同及账号信息按授权脱敏；通用知识与受限客户记录分开提交。没有记录时不推测成交、满意度或原因，建议行动需确认。

## 常用问题
- 已确认的客户需求有哪些共性和典型使用场景？
- 针对常见异议，有哪些有依据的回应和适用边界？
- 客户FAQ的标准答案、适用版本和升级路径是什么？
- 类似工单采用了什么处理方法，如何验证已解决？
- 历史失单或客诉中有哪些可复用经验，哪些原因尚未证实？
- 产品方案与客户需求有哪些已确认的匹配点和缺口？

## 可手动创建的个人计划
- 核对客户需求、产品匹配与待确认承诺
- 跟进商机或工单并记录明确的下一步
- 更新已验证FAQ与升级处理说明
- 完成客户案例或服务复盘
