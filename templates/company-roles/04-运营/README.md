# 运营知识库

## 分类
- 用户与渠道
- 内容与选题
- 活动策划与执行
- 增长实验
- 指标口径与分析
- 用户反馈与协同
- 运营SOP
- 运营复盘与案例

## 整理规则
按目标人群、渠道、动作、指标、反馈和复盘整理。区分运营目标、执行事实、效果数据和原因假设；每项数据注明期间、样本、口径及来源。曝光、点击、转化和留存不可混用，相关性不能直接当因果。对照实验注明分组、干预和限制，失败案例保留影响结果的条件。用户与渠道资料先脱敏，不上传未授权名单；没有依据时不补造ROI或增长率，行动和预算待人工确认。

## 常用问题
- 哪些活动方法有效，适用的人群和渠道条件是什么？
- 相似选题有哪些受众需求、内容角度和效果证据？
- 已有增长实验支持哪些结论，还有哪些混杂因素？
- 不同运营报告的指标口径有哪些不一致？
- 用户反馈中反复出现哪些问题，已有处理方法是什么？
- 哪些运营SOP可以复用，执行前有哪些检查项？

## 可手动创建的个人计划
- 明确本轮运营目标、人群与指标口径
- 完成内容或活动方案与发布检查
- 核对效果数据和用户反馈
- 完成运营实验复盘与方法沉淀
