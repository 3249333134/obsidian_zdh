# 知流工作台

把文档导入 Obsidian，交给 AI 全文分析，再检查标签和归档位置。

## Windows 一键安装

1. 运行 `知流工作台安装器-0.8.0.exe`，从列表选择笔记库，或手动选择已有笔记库文件夹。
2. 点击「安装到此笔记库」。安装器将插件包复制到所选笔记库；升级会先备份旧插件，保留配置和任务。
3. 点击「打开 Obsidian」。如果应用已经打开，请重启或重新加载插件。
4. 打开 Obsidian 的 **设置 → 社区插件**，按应用提示允许社区插件，然后启用 **知流工作台**。安装器不会替你关闭安全限制。
5. 插件自动打开工作台。选择 AI 服务，填写对应 **API Key**，点击「测试连接并开始使用」。

连接测试通过后，目录与 Home 首页自动补齐。已有笔记不会被覆盖。AI Key 需要你在对应服务申请并确保有可用额度。

## 可选公司模式（0.8.0）

工作台新增「公司知识与团队」。同一插件可继续个人使用，也可登录公司，获得公司公共、岗位／部门、跨部门项目空间与岗位模板。已有笔记和个人计划不会自动上传或搬迁。

岗位模板已按管理、产品／项目、研发、运营、销售／客服分别设计：每岗8类知识、专用主笔记结构、6个常用问题和4项可手动创建的计划，另附每岗2份专项模板，共15份Markdown模板。公司页「我的岗位」可直接新建主模板笔记，员工按已分配岗位使用；完整模板包见 [岗位模板说明](ROLE-TEMPLATES.md)。空白模板不会自动发布为共享业务知识，使用模板不扩大权限。

- 管理员进入 [公司管理网页](https://47.115.220.98:3399/company/)，配置公司 AI／搜索服务、岗位、空间负责人和成员，生成一次性邀请。
- 员工在插件填写 `https://47.115.220.98:3399`，用邀请创建账号；之后用账号密码授权当前设备。密码不保存，设备令牌保存在本地插件配置。
- 个人知识经「生成提交预览 → 核对正文与逐项选择附件 → 确认提交审核 → 负责人发布」才成为共享版本。共享笔记变化不会自动发布。
- 公司问答只使用授权知识，由服务器的统一 AI 回答；个人综合问答使用自己的 AI，私有正文不经过公司服务器。公司联网默认关闭，开启时需核对公开检索词。
- 「计划与日程」可切换个人和公司团队；团队任务通过公司服务提交，个人独立日记沿用原连接。执行人可改期和完成，指派与回收由负责人操作。团队复盘先预览再送审。
- 授权副本在 `08_COMPANY-公司知识/`，同步只更新管理区块；个人备注留在区块之外。退出或撤权后清理管理内容，已人工复制或导出的文件无法远程收回。

现有独立日记首页及接口保留。公司后端独立监听服务器回环端口3400，对外通过现有 HTTPS 网关的公司专属路径提供服务。部署、备份、管理员和员工操作见 [公司连接说明](COMPANY-GUIDE.md)，实测范围见 [0.8.0 验收记录](VERIFICATION-0.8.0.md)。公司真实 AI 调用需管理员自行配置有效 Key。

## 使用

- 点击最左侧竖向工具栏中的「知流工作台」图标，在左侧边栏打开工作台，与文件目录作为并列标签保留。重复点击会回到同一个工作台；也可通过命令面板打开。
- 选择或拖入 MD、TXT、可提取文本的 PDF、DOCX。每个文件最多 50 MB；文本应为 UTF-8 或带 BOM 的 UTF-16。
- 文件先进入 `00_INPUT-输入池/sources`。长文档逐段分析，然后汇总所有分段。
- 在「待确认」中修改标题、摘要、标签、目标库、要点与 Markdown 正文，点击「确认归档」。
- 每个文档生成一份整理笔记，原文件移至 `05_ASSETS-资产库/原始文档`，笔记包含来源链接。
- 「处理记录」可打开笔记或重试失败任务；重启时中断的任务需要手动重试。
- 「配置 → 目标库与分类说明」允许新增目录、修改分类说明及停用目标库。修改目录不会搬迁已经归档的笔记。

## AI 配置与数据

内置 Agnes（agnes-2.5-flash，https://apihub.agnes-ai.com/v1）、DeepSeek（deepseek-flash）、OpenAI（gpt-4.1-mini）、通义千问北京地域（qwen-plus）。模型可用性取决于账户权限及服务后续变更。升级保留当前服务配置，选择 Agnes 后在插件中填写新 Key；安装包不包含你的 Key。

高级设置可修改 Base URL、模型名、分块字符数，支持本机 HTTP 接口与远程 HTTPS 接口。通义其他地域 Key 需对应地域地址。第三方服务必须兼容 `/chat/completions`。

API Key 明文保存在 `.obsidian/plugins/knowledge-flow/data.json` 的插件本地配置中，用密码输入框遮罩显示，不会写入生成笔记或日志。请勿公开该文件；若同步插件配置或备份整个 vault，Key 也可能被复制。文档提取内容、分段摘要、已有标签和目标库用途会发送给所选服务。连接测试也会发起一次小额 API 请求。个人模式无需服务器；可选公司模式使用独立的公司服务。

首版没有 OCR、跨笔记库归档、自动最终归档、多笔记拆分及日记自动化。PDF 中若出现没有文字的页面，会提示先做 OCR，避免只分析可读部分。PDF 表格等复杂版式的提取顺序可能与视觉顺序不同，请检查摘要。

## 独立插件包

解压 `knowledge-flow-0.8.0.zip`，将 `knowledge-flow` 文件夹放入笔记库 `.obsidian/plugins/`，再启用插件。Windows 用户优先使用安装器，无需手动复制。

## 独立日记计划与双端同步（0.7.1）

在工作台点击「计划与日程」。此页面复用 Diary 的计划编辑、子任务、重复规则、类别标签、四象限、分类窗口、列表、周／月日程、完成记录和回收站。计划可不属于项目；点击计划标题，在右侧详情中关联项目后，也会计入原有项目进度。

连接步骤：

1. 登录 [独立日记](https://47.115.220.98:3399/)，点击账号旁的「连接 Obsidian」，为这台电脑生成设备授权。
2. 在插件「计划与日程 → 右上角同步状态／设置 → 网站连接与同步」填写网站地址及设备令牌，点击「测试连接并开启自动同步」。此令牌与 AI／搜索 Key 无关。
3. 首次连接下载当前账号已有日记、计划及周复盘。打开 Obsidian 时立即同步，此后每 30 秒检查；保存本地已关联计划后自动提交。关闭 Obsidian 即停止，不安装后台服务。

网站已连接时，新计划默认「本地与网站」，可在快速新建中取消「同时同步到网站」；未连接时保存在本地。旧本地任务不会自动上传；点击计划标题，在详情中预览全部同步字段，再确认接入网站。项目目标、资料、个人正文及本地路径不上传。计划以 Markdown 为正式来源；可以编辑专属属性，其他正文与属性会保留。无效或重复标识显示具体文件并暂停该项。

日程根据**截止日期／时间**展示。拖动时先核对并确认新的截止时间；原定开始时间单独保留。重复日程按可见范围计算，仅保存系列规则和实际修改／完成的期次。修改系列可选择仅本期或本期及以后，已完成历史保留。

计划与日程双向同步；日记、已有周复盘只从网站下载。云端日记位于 `00_INPUT-输入池/每日记录/独立日记-云端/<来源标识>/`，复盘位于 `01_UNDERSTAND-理解层/周复盘/独立日记-云端/<来源标识>/`。本地计划完成记录存入独立的「独立日记-本地」目录。勾选复选框直接完成；需要记日记时使用「更多操作 → 完成并记日记」或详情中的「保存并记完成日记」，不会由同步擅自调用 AI。附件仅保留远端引用。

冲突会显示本地／云端差异，确认后才采用；管理区块之外的个人备注保留。云端删除只标记来源删除／回收状态，本地笔记不永久删除。断开、换账号及网站撤销设备授权都不删除本地知识，也不会自动把旧账号的待提交内容发给新账号。令牌明文存于本地插件配置，遮罩显示；请勿公开配置及包含配置的备份。

源码复用：先运行 `node scripts/build-diary-planning.mjs D:/prj/user/Diary` 构建共享界面，再执行插件构建。`integration/diary/` 是网站接口与设备授权页面的升级源码，`scripts/apply-diary-upgrade.mjs` 将其应用到 Diary；无需重建数据库。部署备份与实测范围见 `VERIFICATION-0.7.1.md`。

### 0.7.1 精简计划操作

左侧集中状态、类别与项目筛选；只保留一个「新建计划」，输入标题即可创建，截止日期与时间可选。点击标题在右侧详情编辑，重复与分类等高级属性默认折叠。常用视图为列表、周、月，四象限和分类窗口放入「更多视图」。记住上次视图，右上角显示同步状态，逐项标明仅本地／正在同步／已同步网站／需处理。

## 软件对话提炼（0.3）

打开左侧「同步」，配置来源后点击「立即同步」，会自动保存并启用该来源。首次启用跳过旧历史；已有对话通过日期范围单独导入。每 30 秒检查新增内容，静默两分钟后提炼，持续更新最长等待十分钟。

- Codex / Work 本地会话：检测 `.codex/sessions`；只接受已识别的主会话来源。内部 Agent、审批记录、环境上下文和工具输出即使包装成 user 消息也会排除，来源不明的文件隔离并显示错误。
- WorkBuddy：检测 `.workbuddy/projects` 中的主会话 JSONL，不采集子 Agent、内部日志、未发送草稿或附件文件。
- TRAE：首版需要导出聊天；选择导出目录。本机已配置 `.obsidian/plugins/knowledge-flow/exports`，在 TRAE 导出时选择这个文件夹。仅选择程序路径不能读取完整对话。
- 导出格式支持 MD、TXT、明确的 user/assistant 消息数组 JSON、messages 包装 JSON，以及已识别的会话 JSONL。未知格式提示错误，不猜测读取。

知识笔记只包含主题与目标、主要信息、推进过程、方案取舍及公开理由、结果与待办。思路仅来自对话里明确说出的理由，不采集内部推理，不补造决策依据。AI 不确定的内容保留不确定性；闲聊、机械状态播报和重复日志不进入笔记。影响方案的失败尝试保留原因与结论。

完整对话正文只在内存中用于分析，不生成逐字 Markdown，不生成原文附件，不永久保存于配置或任务快照。持久化的是提炼草稿、消息指纹、来源、会话标识、时间范围和完成位置。未完成时重新打开 Obsidian 会从来源补读；请保留来源日志或导出文件，否则会明确提示无法恢复。

明显凭据在发送 AI 前遮蔽，但不能识别所有敏感信息。启用来源表示同意将清洗后的有效对话、已有知识草稿、标签和库用途发送给所选服务。无价值内容显示「无需入库」；有效知识进入「待确认」。确认后才写入目标库，后续更新也需确认；一段会话维护一份主笔记。手工修改过的已归档笔记不会被覆盖。

升级旧同步数据时先生成一次备份：`.obsidian/plugins/knowledge-flow/migration-backup-v03/`。该备份是旧配置和逐字记录的保留副本，包含 Key，应妥善保管。仅移出未被手工修改的插件生成逐字记录，其他文件保留并提示；旧分析任务失效后重新提炼。本次已选定的历史日期是 2026-10-08 至 2026-10-14，不会因跨过午夜扩大范围。今后的同步不持续备份完整正文。

来源读取错误显示在「同步」，提炼或归档失败显示在「记录」，可独立重试。AI 格式错误最多补正一次，仍失败会提示。仅 Obsidian 打开时监控，无后台常驻程序、独立 ChatGPT 采集、屏幕或键盘监听。

## 升级与恢复

安装器只更新自身清单中的运行文件，不删除其他插件、笔记或工作流目录。旧插件备份位于 `.obsidian/knowledge-flow-backups/`。配置和任务原样保留；数据格式不兼容时插件会拒绝覆盖配置。备份包含 Key，请妥善保管。

升级时请先关闭 Obsidian，完成后再打开，以免正在运行的旧插件写入配置。安装失败会尝试回滚并显示原因。停用或卸载插件不会删除生成的笔记和原文件。

## 搜索、关系图谱与 AI 问答（0.4）
点击左侧工作台的【搜索与问答】，主区会打开独立页面。搜索整个笔记库的 Markdown 标题、正文、标签和属性；配置、备份、逐字记录和未确认材料不参与检索。搜索先显示本地结果，再按需生成 AI 关联。图谱实线表示已有链接、点线表示共同标签、虚线表示 AI 建议，点击节点查看依据并打开笔记，拖动和滚轮可调整视图。
首批显示 50 份结果及至多 150 个图谱节点，点击【加载更多】浏览下一批图谱。AI 关联每批最多处理 20 份摘要，缓存不包含全文，并会在内容或模型改变后重新生成。
输入问题并点击【查证并回答】，系统先检索并沿图谱扩展至多两层、最多 20 份笔记，再回答并显示可点击的章节引用。AI 只能使用笔记证据，资料不足会说明；外部链接和图片不作为回答导航，核对请使用【笔记引用】。问题、历史与相关片段会发送至配置的 AI 服务。
可追问、重试、停止等待或新建问答。停止仅忽略迟到结果，不保证撤销服务端请求或费用。问答不自动保存，关闭页面后不保留聊天。已有导入、配置及自动同步继续正常使用。

### 0.4.1 问答与界面修复
搜索图谱和 AI 问答使用独立模式，点击顶部【AI 问答】即可提问。问答进度和错误紧邻提问框显示，处理期间阻止重复提交，可以停止等待。引用使用短证据编号并映射到实际笔记章节，兼容带说明的 JSON 和中文引用括号。AI 关联每次优先分析 12 份相关摘要，默认关闭共同标签连线以减少图谱拥挤；可勾选显示。图谱按显示宽度布局，节点文字不再被整个 SVG 缩成极小字号。

0.4.1 最终引用流程：AI 直接输出 Markdown，使用原始证据标记如 [E1]；插件验证并转换为可追溯的显示引用，避免证据编号与引用顺序混淆。点击工作台【搜索与问答】时自动收起左栏，给主区更多空间；用顶部侧栏图标可展开。

## 联网综合研究与回答归档（0.5）
进入【配置】→ 展开【联网研究 · 服务与 Key】，填写 Tavily Key 并点击【测试联网并保存】。搜索 Key 与 AI Key 分开保存，无需更换当前 Agnes 模型。可在 https://app.tavily.com/ 获取自己的搜索 Key；插件不代购或自动购买额度。
AI 问答默认开启联网研究。每次先沿本地图谱取证，再生成 3 条公开检索词，必要时最多补至 5 次检索；去重最多保留 12 个候选来源、读取 8 个网页。正文无法读取时明确显示只使用摘要。Tavily 不接收本地笔记正文、文件路径或完整聊天；AI 负责综合相关片段。默认中文行业问题以中国为主、国际对照，用户指定的范围优先。
完整研究回答通常为 1500–3000 字，包含事实依据、分析、建议、行动项与局限。通用框架和综合判断与可核验事实区分；不编造缺失统计数据。回答分别展示本地章节引用与网络来源、发布时间和检索时间。联网失败会明确降级，不会声称完成网络研究。未配置 Tavily 时请填写 Key，或关闭联网使用本地资料与通用框架。
回答旁点击【归档到知识库】，系统保存待确认草稿并推荐标题、标签、目标库；可编辑正文后点击【确认归档】。归档仅产生一份 Markdown 主笔记，保留问题、回答、引用、来源与研究范围，不保存网页全文、聊天全文或额外原文件。重复点击及中断重试避免重复产物，不覆盖手工修改笔记。归档后立即参与本地检索。
研究进度显示在提问框旁，可查看检索词和候选来源数，停止等待后忽略迟到结果；服务端可能仍处理已发送请求。Tavily 与 AI 按各自服务规则计费。网络实测需提供有效搜索 Key。

## 可切换的联网服务（0.5.1）
配置 →【联网研究 · 服务与 Key】新增联网服务选择，独立于上方的回答模型。Tavily 与 Agnes 的 Key 分别保留，切换服务不会清空旧 Key。可随时替换各自的遮罩输入值；保存联网配置不影响导入任务、同步游标和已有笔记。

Agnes 提供能力检测入口，可复用上方**已保存**的 Agnes AI Key，或取消勾选后填写单独的联网 Key；联网模型也可单独修改。点击【测试联网并保存】仅发送公开的 Obsidian 文档搜索词，不发送本地笔记。测试必须取得服务返回的搜索完成事件和结构化网页引用才判定成功，不能将聊天回复中的网址视为真实搜索。

**当前限制：**2026-10-15 本机检测 Agnes Responses：兼容的 `web_search_preview` 请求返回 HTTP 200，但没有搜索完成事件与网页引用，检测不通过。因此当前 Agnes 仍可综合回答，尚不能承诺它替代 Tavily 完成联网检索。官方文档介绍 Responses 与函数调用，并未明确承诺原生搜索已开放；取得官方搜索接口资料后可继续接入。Agnes 入口用于再次检测账户或服务能力变化，不是已验证可用的搜索服务。

测试失败会在当前配置页显示原因，且不更改原先保存的联网配置。【保存联网配置】可以保存尚未验证的选择；选择不支持搜索的服务后，研究会明确提示失败与降级，不伪称联网成功。切回 Tavily 后原 Key 仍在；未配置有效搜索服务时可关闭【联网研究】，继续使用本地资料与通用框架。
## LangSearch 联网搜索（0.5.2）
在【配置】→【联网研究 · 服务与 Key】中，将联网服务切换到【LangSearch · 网页搜索（免费方案）】，填写 **LangSearch 自己的 API Key**，再点击【测试联网并保存】。上方 AI 服务继续使用 Agnes，无需更换 Agnes Key。点击【申请 LangSearch Key】可前往 https://langsearch.com/ 注册获取；Key 直接填入插件，不需要在聊天中发送。

官方目前提供免费方案，但有账户速率、每分钟和每日 token 限制，以账户控制台为准：https://docs.langsearch.com/limits/api-limits 。查询与返回文字都会消耗免费用量；Agnes 或其他回答模型的用量独立计算。超限不会自动切换到其他付费搜索服务。

接口依据官方文档 https://docs.langsearch.com/api/web-search-api ，使用 `POST https://api.langsearch.com/v1/web-search` 和 Bearer 认证。每个公开检索词最多请求 5 个结果及每个来源最多 3000 字符的网页文字，沿用每轮 3–5 次搜索预算；去重候选最多 12 个，最多选择 8 个网页来源参与综合分析。搜索响应已提供文字，不调用额外提取接口。服务仅返回摘要或没有正文时会说明，不会伪称已读取全文。搜索失败仍保留本地分析能力并显示降级原因。

LangSearch、Tavily 和 Agnes 联网 Key 分别保存，来回切换不清空其他 Key。LangSearch Key 通过遮罩输入，可替换；不会写入安装包、笔记和日志。连接失败不覆盖原有已保存配置。已有同步、任务和归档笔记保持兼容。

配置完成后，在【搜索与问答】→【AI 问答】开启【联网研究】，提问即可执行“本地检索＋LangSearch 网页资料＋Agnes 综合分析”。回答保留可点击来源，并可点击【归档到知识库】预览、编辑和确认归档。未提供有效 LangSearch Key 前，仅完成接口模拟验证，不宣称真实联网已验证。
## 项目管理与知识融合（0.6）
左侧工作台新增【项目管理】，在主区打开项目总览、任务列表、周日程、AI 建议及周复盘草稿。全部插件页面采用浅紫色界面，支持 Obsidian 深色主题；不会修改其他插件或笔记页面样式。窄窗口通过【筛选／项目与任务／本周与资料】切换，不把多栏挤在一起。

### 项目与任务
新建项目后填写目标、类别和状态。0.7 起计划可以不关联项目，项目导航中的周日程也进入共享 Diary 日程：按截止时间展示，拖动先预览确认新的截止时间，保留原定开始时间。原项目任务的标识、路径、链接及执行日期仍兼容。任务完成后可重新打开或取消；取消任务不计入完成率。类别可新增与重命名。

正式数据保存为普通 Markdown：`03_BUILD-项目沉淀/项目管理/<名称>-<短标识>/项目主页.md` 与其任务子目录。`kf_` 属性包含稳定标识、状态、时间和来源。界面会重新读取笔记，停用插件后仍可阅读；项目、任务和复盘会参与知识搜索与关系图谱。项目归档只隐藏默认活跃列表，勾选【包含已归档项目】可查看。

用户正文请写在【我的记录】等插件管理区块之外，未知属性和区块外的手写内容会保留。管理区块用于展示项目任务与资料链接，有校验保护，手动修改会阻止覆盖并提示。手动调整属性后刷新生效；无效字段、重复标识或项目缺失会显示问题笔记。笔记重命名时更新插件关联链接，文件移出项目管理目录后应作为普通笔记处理，不自动在其他目录重建。

### 旧资料和 AI 行动
【扫描已有项目资料】先选择现有项目沉淀目录内的1–20篇笔记，AI 仅使用所选摘要建议分组。你可以修改名称、目标或选择已有项目，再确认资料关联；原笔记不移动、不改写。已接入项目的资料可继续【提取行动】，仅勾选的待办会在确认后创建。

导入文档、研究回答和对话提炼的归档预览新增【AI 推荐项目与待办】。选择项目、勾选确认关联及具体待办，然后确认归档。也可以完全跳过项目建议，正常归档知识。正文变化后建议失效，需重新提取；不会把讨论自动标为完成，不推断截止日期。重复确认或同一来源再次提取相同行动避免重复建任务。

已归档 Markdown 可通过文件右键菜单／命令面板【从当前笔记提取项目行动】，或工作台记录中的【提取项目行动】接入。项目详情【基于本项目提问】优先选择项目及关联笔记，再沿知识图谱扩展，联网继续使用配置好的 LangSearch 等服务。AI 仅生成建议，必须人工确认。

### 周复盘与恢复
【生成周复盘】按当前项目筛选范围和设备本地时区的本周记录生成进展、问题、决策与下周建议。可编辑预览、核对来源，确认后写入 `01_UNDERSTAND-理解层/周复盘/`，并链接回项目。未确认草稿保存在插件配置中，不进入知识索引；已保存复盘再次确认不会重复产生文件或覆盖手工修改。

项目写入操作先持久化预留路径，写入中断会显示【继续未完成写入】，逐步恢复并检查内容变化。已有用户修改不会被覆盖；发生冲突请打开问题笔记核对。升级保留 Key、同步游标、导入记录及已有笔记。0.7 已加入 Diary 四象限、月视图与计划回收站；没有多人协作或外部日历同步。

AI 功能使用当前配置的文本服务，会发送相关知识片段、候选项目摘要或复盘所需记录，并遮蔽已配置的 Key。旧资料扫描、提取行动和复盘均由用户触发。AI 不可用时手动项目管理与日程不受影响。
验收说明：项目 AI 提取及复盘已使用合成样例完成真实服务验证；本机保留的“验收演示”项目只作验收追溯，可在包含归档项目时查看。AI 草稿可能过度概括，确认前请核对来源、完成日期和进展描述；生成复盘不会代替你核实事实。
